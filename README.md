# Python-Basic-Expense-Tracker-Project

A beginner-friendly Python application that helps users record, categorize, and analyze their expenses through a simple command-line interface.

This project was built to practice Python fundamentals such as functions, lists, loops, conditional statements, and user input handling.

---

## 🚀 Features

* Add expenses under different categories
* Record multiple expense entries
* Categorize spending effectively
* Calculate total expenses for each category
* Easy-to-use command-line interface
* Beginner-friendly project structure

---

## 📂 Expense Categories

The tracker currently supports the following categories:

* 🍔 Food
* 🎬 Cinema
* 💳 Loan
* ✈️ Trip
* 🚌 Transportation
* 📦 Others

---

## 🛠️ Technologies Used

* Python 3

---

## 📋 How It Works

1. Select an expense category.
2. Enter the number of expense entries.
3. Add expenses one by one.
4. View recorded expenses.
5. Calculate the total amount spent in the selected category.
